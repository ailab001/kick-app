# Kick - 게임 기반 AI 데이터 경제 플랫폼

> AI를 배우는 게 아니라, AI를 직접 만드는 곳

Kick은 아이들의 학습 과정을 데이터 자산으로 전환하는 게이미피케이션 교육 플랫폼입니다.

---

## 📌 프로젝트 소개

### 핵심 아이디어
- 아이들이 게임 미션을 수행하는 **모든 과정**이 데이터로 수집됩니다
- 수집된 데이터는 **기여도에 따라 보상**되며, 플랫폼 내 경제 활동으로 연결됩니다
- 기업은 **정제된 학습 과정 데이터**를 확보할 수 있습니다

### 해결하는 문제
1. **학습자(아동)**: 코딩 교육의 결과물이 '수료'나 '점수'에 그치는 문제
   - 자신의 시도와 노력이 실질적인 가치(보상)로 환산되는 구조 제공

2. **기업(AI/에듀테크)**: 10대의 사고방식과 행동 패턴 데이터 확보 어려움
   - 학습 과정의 시행착오 데이터를 고품질로 제공

## 🎮 주요 기능

### 1. 게이미피케이션 학습
- **캐릭터 커스터마이징**: 피부, 머리, 상의, 하의, 악세서리 꾸미기
- **블록 코딩 미션**: AI 개념, 조건문, 반복문, 함수 등 학습
- **XP/레벨 시스템**: 학습 진행도에 따른 보상

### 2. 데이터 경제 시스템
- **행동 데이터 수집**: 모든 플레이 과정이 로그로 기록
- **기여도 정산**: 데이터 품질에 따른 포인트 지급
- **투명한 데이터 공개**: 수집 중인 데이터를 실시간 확인 가능

### 3. C2C 마켓플레이스
- **크리에이터 에셋 판매**: 사용자가 만든 캐릭터 에셋 거래
- **실시간 정산**: 판매 수익 80% 크리에이터에게 분배
- **글로벌 마켓**: 전 세계 사용자와 거래

## 🚀 시작하기


## 🎯 프로토타입 주요 화면

1. **캐릭터 탭**: 기본 캐릭터 표시 + 프리셋 선택 (다크 시크, 파스텔 팝, 사이버 펑크)
2. **미션 탭**: 3가지 블록 코딩 미션 (AI 학습, 조건문, 반복문)
3. **마켓 탭**: C2C 크리에이터 에셋 거래소 (6개 아이템)
4. **기여도 탭**: PoC(Proof of Contribution) 스코어 대시보드 + 정산 시스템
5. **크리에이터 탭**: 수익 현황, 주간 활동, 데이터 활용 이력
6. **데이터 카탈로그 탭**: B2B 라이선싱용 행동 데이터셋 목록
7. **데이터 패널** (우측): 실시간 이벤트 스트림 + 품질 메트릭스
